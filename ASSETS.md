# Изображения «Ветвь»

Созданы встроенным ImageGen специально для этого проекта. Финальные фотографии находятся в `public/images/`.

Общий запрос: премиальная редакционная фотография для каталога цветочной мастерской, целый букет по центру со стеблями и простой шёлковой лентой, мягкий серо-кремовый студийный фон, естественный дневной свет, без текста, рук и вазы.

| Файл | Состав |
|---|---|
| quiet-morning.webp | Белые садовые розы, белая эустома и эвкалипт |
| pink-air.webp | Нежно-розовые садовые и кустовые розы, лёгкая зелень |
| sunny-letter.webp | Персиковые розы, абрикосовые гвоздики, небольшие ромашки |
| lilac-evening.webp | Сиреневая эустома, фиолетовая статица, лавандовые розы |
| feelings-aloud.webp | Бордовые и красные розы, тёмные сливовые акценты |
| green-story.webp | Белая гортензия, лаймовый вибурнум и зелёные ветви |

Логотип `brand-mark.png`: лаконичная ботаническая монограмма «В», тёмно-зелёная плавная ветвь с тремя листьями, без текста. Генератор вернул фон с клеткой вместо прозрачности; при отображении используется CSS-фильтр контраста и смешивание с фоном. Иконка вкладки — типографическая строчная «в» в цветах марки.
