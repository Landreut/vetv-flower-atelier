# Ветвь — цветочная мастерская

Каталог авторских букетов с выбором нескольких композиций, анкетой заявки, картой мастерской и вертикальной каруселью отзывов.

Живая версия: https://vetv-flower-atelier.yuuyuuuuxd.chatgpt.site

## Локальный запуск

```bash
pnpm install
pnpm dev
```
